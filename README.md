# Strumenti per i siti web scolastici

Raccolta di script e strumenti sviluppati per migliorare la grafica e la gestione dei siti web istituzionali delle scuole, con particolare attenzione ai siti che utilizzano il frontend di Spaggiari.

Il progetto nasce dall'esperienza diretta di un animatore digitale, con l'obiettivo di offrire soluzioni semplici, documentate e facilmente adattabili da altri istituti. Ogni strumento è contenuto nella propria cartella, con un README dedicato che ne spiega funzionamento, requisiti e installazione.

## Cosa contiene

| Strumento | Descrizione |
|-----------|-------------|
| [elenco-documenti](./elenco-documenti/) | Pagina che mostra in elenco i documenti (PDF, Word, Excel) presenti sul server, organizzati per cartella, con ricerca e download. I file possono essere caricati i nuna cartella via FTP o Wordpress e visualizzati in una pagina pubblica o riservata. |

*Altri strumenti verranno aggiunti nel tempo.*

## Principi

- **Semplicità:** gli strumenti devono funzionare con un'installazione minima, senza dipendenze complesse.
- **Trasparenza:** il codice è leggibile e commentato, così ciascuno può verificarlo prima di usarlo.
- **Riservatezza:** nessuno strumento contiene credenziali, dati personali o riferimenti a server reali. Gli esempi usano dati fittizi.

## Avvertenze

Il progetto è indipendente e non è affiliato a Gruppo Spaggiari né ad altri fornitori di registro elettronico o servizi per la scuola. I marchi citati appartengono ai rispettivi proprietari.

Prima di utilizzare uno strumento su un sito istituzionale, è consigliato verificarne il funzionamento su un ambiente di prova e confrontarsi con il proprio referente tecnico e con la dirigenza.
